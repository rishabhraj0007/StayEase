# StayEase - Student Accommodation Website

## Live Demo

https://stayease.rf.gd/index.php

## Project Overview

StayEase is a responsive web application that helps students find suitable accommodation. Users can browse PG properties, view property details, register accounts, log in, and mark properties they are interested in.

## Features

* User Registration
* User Login
* Property Listings
* Property Details
* Interest/Shortlisting System
* AJAX-Based Interactions
* Responsive Design
* Live Deployment

## Installation

1. Clone the repository.
2. Import the SQL database into MySQL.
3. Configure database credentials.
4. Run the project using XAMPP.
5. Open the project in a web browser.
